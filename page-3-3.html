Assessment Overview

Evaluate the effectiveness of a seven-week performance improvement programme using biophysical principles and sociocultural factors.

Task Outline

  • Task 1: Baseline data collection & initial skill analysis.
  • Task 2: 7-Week Training Log tracking session goals, motor learning, biomechanics, functional anatomy, and reflections.
  • Task 3: Critical Evaluation Essay addressing biophysical learning, sociocultural assumptions (healthism, technocentricity, scientism, commodification), and proposed modifications.
